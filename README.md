
# 🌙 Beyond The Stars

**Beyond The Stars** is a beautiful, interactive, and personalized memory website designed to create a special digital experience through photos, videos, music, and heartfelt messages.

The website features a beautiful night-sky theme with glowing stars, an animated moon, and elegant page transitions.

## ✨ Features

- 🔐 **PIN Lock Screen** – A special password-protected entry.
- 💬 **Interactive Chat** – A personalized conversation experience.
- 📸 **Photo Gallery** – Displays memorable photos with individual messages.
- 🎬 **Video Section** – Watch special moments and memories.
- 🎵 **Background Music** – Enjoy music while exploring the website.
- 💌 **Surprise Letter** – A special final message.
- 🌌 **Animated Night Sky** – Moving stars, glowing moon, and beautiful effects.
- 📱 **Responsive Design** – Supports mobile phones and desktop screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser.
4. Enter the PIN to explore the website.
5. Navigate through the memories, videos, music, and final surprise.
